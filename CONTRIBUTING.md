# Contributing

1. Create a focused branch from `main`.
2. Keep diagnostics read-only and document any new network request or timeout.
3. Never commit credentials, `.env`, `wp-config.php`, dumps, private keys, production output or internal addresses.
4. Add or update documentation and tests where practical.
5. Run the local checks documented in the README and wait for CI before review.
6. Submit a pull request with reproduction context that contains no sensitive data.

Please do not include real hostnames, IP addresses, account names or command output from production. Use placeholders.
