# Security policy

Use these scripts only in an authorized environment and prefer staging. They are intended to be read-only, but operators must review the exact version and permissions before execution.

Please do not report secrets, credentials, personal data, database dumps, private keys or internal addresses in a public issue. For a suspected exposure, stop using the affected release and contact the repository maintainers privately through the GitHub organization.

Supported baseline: PHP 7.4+, Bash with curl, and Windows PowerShell 5.1+. Some checks need WordPress, PSScriptAnalyzer or ShellCheck and cannot be fully validated in CI.
